
## Affiliate links

This build now has affiliate-ready Hotel and Flight search buttons.

- **Hotels:** Booking.com + Agoda
- **Flights:** Booking.com flight search
- **Destination/places:** existing destination UI remains intact
- **Tracking:** IDs are read from `affiliate-config.js`

Before publishing, replace `YOUR_BOOKING_AID` with your approved Booking.com affiliate AID and `YOUR_AGODA_CID` with your approved Agoda CID. The official programs support website links/tools and tracking identifiers. If the placeholders remain, the buttons still open the supplier search pages without affiliate tracking.

### What is live now

The site sends hotel searches to Agoda/Booking.com with the configured tracking identifier and sends the Flight button to Booking.com’s flight-search page with the configured AID.
